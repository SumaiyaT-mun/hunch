# HUNCH 🕵️

### Your instincts vs. the internet.

HUNCH is an interactive scam-awareness game that tests how well you can spot suspicious online messages and social-engineering tactics.

Instead of simply telling you what a scam looks like, HUNCH puts you inside realistic scenarios and asks you to trust your instincts.

## 🎮 How It Works

1. Enter a scenario.
2. Read the message and identify the red flags.
3. Choose what you would do.
4. Discover whether your hunch was correct.
5. Learn why the situation was safe, suspicious, or dangerous.
6. Earn XP and progress through increasingly difficult scenarios.

## ✨ Features

- Realistic scam scenarios
- Multiple difficulty levels
- Interactive decision-making
- Red-flag explanations
- XP and scoring system
- Progress tracking
- Timed challenges
- Final scoreboard

## 🛠️ Built With

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/SumaiyaT-mun/hunch.git
cd hunch
```

Install dependencies :
```bash
npm install
```

Start the development server:
```bash
npm run dev
```
Then open http://localhost:3000 in your browser.
